Google login & cloud sync

Hubungkan project Supabase milikmu sekali. Setelah Google OAuth dan database disiapkan, kamu dapat login dengan Google yang sama dari HP maupun laptop.

Cloud belum dikonfigurasi.
Penting: jangan masukkan service_role key. Gunakan hanya anon/public atau publishable key. Jangan bagikan file konfigurasi atau token login.

Setup cloud satu kali

  1. Buat project di Supabase dan salin Project URL serta anon/publishable key ke kolom di atas.
  2. Di Supabase → Authentication → Providers, aktifkan Google.
  3. Di Google Cloud Console, buat OAuth Client ID tipe Web. Tambahkan URL callback Supabase yang ditampilkan pada pengaturan provider Google Supabase sebagai Authorized redirect URI.
  4. Masukkan Client ID dan Client Secret Google ke provider Google di Supabase.
  5. Di Supabase → Authentication → URL Configuration, masukkan alamat website yang akan dipublikasikan sebagai Site URL dan Redirect URL yang diizinkan. Untuk pengujian lokal, gunakan alamat origin lokal yang sesuai.
  6. Jalankan SQL berikut satu kali di Supabase → SQL Editor.
create table if not exists public.user_finance (
  user_id uuid primary key references auth.users(id) on delete cascade,
  data jsonb not null default '{}'::jsonb,
  updated_at timestamptz not null default now()
);
alter table public.user_finance enable row level security;

drop policy if exists "Users can read own finance" on public.user_finance;
drop policy if exists "Users can insert own finance" on public.user_finance;
drop policy if exists "Users can update own finance" on public.user_finance;

create policy "Users can read own finance"
on public.user_finance for select to authenticated
using (auth.uid() = user_id);
create policy "Users can insert own finance"
on public.user_finance for insert to authenticated
with check (auth.uid() = user_id);
create policy "Users can update own finance"
on public.user_finance for update to authenticated
using (auth.uid() = user_id)
with check (auth.uid() = user_id);

Setelah setup, klik “Simpan konfigurasi” lalu “Lanjutkan dengan Google”. Di perangkat lain, buka alamat website yang sama, masukkan URL dan public key, lalu login dengan akun Google yang sama.

Penyimpanan lokal tetap menjadi cache/backup browser. Data lintas perangkat baru aktif setelah project cloud dan Google OAuth berhasil dikonfigurasi.
